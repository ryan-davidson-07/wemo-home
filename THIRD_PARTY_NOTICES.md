# Reference source attribution

The archived wemo-sos/WemoControlIOS source was reviewed as a reference before
writing Wemo Home. Its SwiftUI lifecycle and SOAP framing were studied. Wemo Home
uses a new core/state architecture and does not include its subnet scanner or
copy its source files. The reference licence is retained here for attribution
and to preserve its terms if any reviewed framing is considered derived material.
There is no runtime dependency on this project.
